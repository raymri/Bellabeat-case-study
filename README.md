# Bellabeat-case-study

This project was completed as part of the **_Google Data Analytics Professional Certificate_**.

The objective of the analysis was to explore smart device usage data to understand how consumers use health-tracking technology and to identify insights that can help Bellabeat company to enhance it's marketing strategy and product development.

# Tools Used
 **Excel** : Data cleaning and pre-processing
 **Power BI** : Data visualisation and dashboard creation
 **Power Query** : Data transformation and model building

# Analysis

1. Data Collection
   Used the Fitbit Fitness tracker dataset available on Kaggle.
   Reviewed structure, missing values and data quality issues.

2. Data Analysis
   Explored correlations  between physical activity, calories burned and sleep duration.
   Identified user behavior trends by weekday/weekend and active minutes.
   
4. Data visualisation
   Designed interactive dashboard in Power BI to highlight usage trends, calories and activity levels.

5. Presentation
   A detailed powerpoint presentation was created to visually summarize each step of the analysis- from data preparation to insights and recommendations.

# What I learnt?

How to clean and transform datasets for analysis.
Building interactive dashboards and visuals in PowerBI.
Applying analytical thinking to derive data driven business insights.
Presenting findings clearly for non technical stakeholders.
